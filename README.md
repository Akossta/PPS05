# Definición
Esta aplicación escrita en Phyton, y su funcion es comprobar si una palabra o frase es palindroma.

# Instrucciones

## 1.Instalación
Debemos copiar los siguientes archivos juntos en una carpeta.
- charfun.py
- check_charfun.py
## 2.Uso
Despues ejecutaremos desde un cmd:
~~~
python charfun.py
~~~
el programa nos solicitara una palabra por consola, comprobará mediante la funcion *esPalindromo*
y nos devolvera el resultado

## 3.Test
Para lanzar la bateria de pruebas, debemos ejecutar el siguiente programa:
~~~
python checkcharfun.py 
~~~

La bateria de prueba consiste en comprobar si es capaz de detectar;
- Espacios en blanco.
- Números.
- Caracteres especiales.
